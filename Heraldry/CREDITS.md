# Credits

Art shipped with Heraldry and where it comes from. Generated by `tools/credits.py` from
`Library.lua`; edit the manifest, not this file.

## Heraldry's own icon

`media/heraldry.tga` (the add-on list, minimap button and add-on drawer icon): "Checked shield" by Lorc, from game-icons.net, <https://game-icons.net/1x1/lorc/checked-shield.html>, CC-BY-3.0. Changes: tinted gold, black fill and outline added, resized.

## Game icon names

`IconNames.lua` (names for the built-in game icons): player ability spell IDs from WoW Forever's spell tables, as exported by <https://wago.tools>, and labels made from the icons' file names, as collected by the community listfile, <https://github.com/wowdev/wow-listfile>. The names are Blizzard Entertainment's; this file is not covered by Heraldry's MIT license.
