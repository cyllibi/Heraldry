# tools\gameicons2lib.py reads this list, downloads each icon, fills enclosed areas black,
# adds a black outline and writes the textures and the game-icons block of
# Heraldry\Library.lua.
#
#   {Category}                            the picker's category for the lines that follow
#   [tags]                                search words for the lines that follow
#   author/name                           an icon: key gi_<name>, display name its title case
#   author/name = Display name            a display name of its own
#   author/name | more tags               search words for this icon only
#   author/name = Display name | more tags
#
# Keys are stored in players' rules: once an icon has shipped, don't remove or rename it.
# Check new icons at 20 px (the nameplate size) before adding them; busy art turns to mush.
# Tags game-icons.net uses that nobody searches for are dropped by the tool (STOP_TAGS).
